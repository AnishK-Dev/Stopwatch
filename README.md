# Stopwatch ⏱️

A sleek, responsive, and high-precision web stopwatch. 

This project features a clean, user-friendly interface powered by precise timing logic to handle accurate time tracking down to the millisecond. Built with a focus on smooth UI performance, it provides seamless core time-management controls in a lightweight wrapper.

---

## 🚀 Features

*   **Precision Timekeeping:** Tracks elapsed time with high precision, handling minutes, seconds, and milliseconds smoothly.
*   **Core Controls:** Fully integrated actions for **Start** (begin tracking), **Stop** (pause current progress), and **Reset** (wipe state back to zero).
*   **Responsive UI:** Optimized to scale and display cleanly across desktop monitors, tablets, and mobile devices.

---

## 🛠️ Tech Stack

*   **Structure & Semantics:** HTML5
*   **Styling & Design:** CSS3 (Flexbox/Grid layout, modern typography)
*   **Logic Engine:** Vanilla JavaScript (`setInterval` / `requestAnimationFrame` mechanics)
